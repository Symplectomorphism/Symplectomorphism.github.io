## Selection decisions

- Combined packets retain their original pages. The public descriptions explicitly limit practice to the named solved questions.
- Rigid-body-motion packet: Problems 9, 15, 16, 21, 35, 36, 37.
- Velocity packet: Problems 3.28 and 3.34; the separate revised 3.28 solution takes precedence.
- Ancillary 1: Questions 1–3; programming Question 4 is excluded.
- Ancillary 3: Questions 1–6 and 7(c); code for 7(a–b) is unavailable.
- Skills test: Question 1(a–g); Question 2 has no written solution.
- Ancillary 2 uses the matching older Homework II key. The file named ancillary_2_solutions_full.pdf combines unrelated assignments and is not used.
- Ancillary 4 has a matching key with an older Ancillary 3 heading.
- Ancillary 7 and 8 reuse older Homework VI and VII solutions; these relationships are described on the page.
- The 2020 Midterm II and final keys contain their own questions. They are included as self-contained worked collections, without attaching mismatched question papers.
- The 2019 in-class and 2021 final question papers were excluded because the corresponding filenames contain keys for different questions.
- Student submissions, grade records, full commercial solution manuals, question-only banks, and duplicate copies were excluded.
- The standalone Newton-Raphson example repeats the Homework II key and needs no additional entry.

## Scope of verification

This collection verifies availability and matching of archived solutions. It does not independently certify every derivation or numerical answer in the original documents.
